# Challenge 6 – Wireshark Packet Detective

**Category:** Network Security  
**Difficulty:** Medium  
**Points:** 30  
**Topic:** Network Traffic Analysis

## 📌 Project Overview
This challenge focuses on analyzing network packet summaries using Wireshark concepts. It covers DNS resolution, TCP three-way handshake, HTTPS communication, and TLS protocols.

## 🔍 Challenge Analysis

1. **DNS:** Resolves domain names into IP addresses.
2. **Destination Port:** Port 443 is used for HTTPS communication.
3. **Transport Protocol:** TCP establishes the connection.
4. **TCP Three-Way Handshake:**
   - Packet 3 – SYN
   - Packet 4 – SYN-ACK
   - Packet 5 – ACK
5. **Protocol After Handshake:** TLS Client Hello.

## 🛠️ Key Concepts Learned

- Common network ports

- TLS protocol
- Wireshark packet analysis
